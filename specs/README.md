# Synthesizer Project Specifications

This directory contains the authoritative technical specifications and design documents for the analog synthesizer emulator.

## Documents

- [architecture.md](architecture.md): Overall system architecture, threading model, and audio/UI inter-thread communication.
- [dsp_spec.md](dsp_spec.md): Audio digital signal processing (DSP) specifications (Oscillators, Filters, Envelopes, Voices).
- [ui_spec.md](ui_spec.md): User interface design, keyboard mapping, mouse interaction, and visual feedback.
- [roadmap.md](roadmap.md): Feature roadmap across implementation phases.
